# Nexus Capture

Goal: capture an explicit screenshot, browse screenshots/clips with the controller,
and optionally use GameHQ for real rolling replay and in-game Share/Guide controls.

Architecture: Capture subscribes to Core game sessions. Nexus writes its own PNGs
and indexes approved media folders. A separate installed GameHQ companion records
replays. Its documented local protocol negotiates capabilities before lifecycle
messages; it does not expose a capture/replay command. No synthetic hotkeys or
undocumented recording commands. No automatic recording without opt-in.

- [x] Implement bounded folder index and authorized streamed media, including Range.
- [x] Screenshot writer with explicit invocation, unique filenames and game context.
- [x] Optional official GameHQ installer, verified digest, launch and local bridge.
- [x] Console gallery, image/video viewer, source picker, filters and FR/EN copy.
- [x] Navigation, safe IPC, shortcut, native Electron QA and regression tests.
- [ ] Document remaining limitations and publish verified sources/release.

Tests: symlink/path escape, partial files, oversized indexes, duplicate screenshots,
failed capture not announced as saved, missing engine, unsupported pipe capability,
broken frames/timeouts, range playback, late UI replies and dialog focus.

Media is read-only apart from screenshots explicitly created by Nexus. Folder
import and gallery refresh do not delete, move or share user media. No remote uploads.
