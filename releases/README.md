Local verified build copies are grouped by version (`releases/v2.2.0/`). Binaries are ignored by Git. GitHub Actions builds and publishes the official files; its SHA256 manifest describes those exact files. Local builds have their own checksum manifest and can differ byte-for-byte from CI builds.

Historical or incomplete build attempts belong in a local backup outside the repository.
