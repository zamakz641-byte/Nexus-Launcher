# Releases

Official Windows executables are published on [GitHub Releases](https://github.com/zamakz641-byte/Nexus-Launcher/releases). The V2.0 assets are [Setup](https://github.com/zamakz641-byte/Nexus-Launcher/releases/download/v2.0.0/Nexus-Launcher-Setup-2.0.0-x64.exe) and [Portable](https://github.com/zamakz641-byte/Nexus-Launcher/releases/download/v2.0.0/Nexus-Launcher-Portable-2.0.0-x64.exe).

Use this directory for local copies of published installers, grouped by version (`releases/v2.0.0/`). Binaries are ignored by Git. Local packaging output is generated in `frontend/release/` and must be verified before publishing. Historical or incomplete build attempts belong in a local backup outside the repository.
