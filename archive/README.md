# Archived editions

`legacy-python-v1.7/` contains the earlier Python/pywebview launcher, its old React prototype, tests, scripts, plans, and patch notes. It is kept as source history and is not part of the Electron V1.0 build.

The maintained app is in [`../frontend/`](../frontend/). The archive was moved intact from the repository root; no game installations or user data were moved.

`old-audio-tools/` preserves the earlier Runway sound download script. Its signed download URLs are historical and it is not part of the current “Minimal · tactile” sounds.
