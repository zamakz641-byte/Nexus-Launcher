# Nexus Launcher V1.0

The first Electron edition of Nexus Launcher brings a cinematic, controller-friendly Windows game library.

## What's included

- Home, Library, Search, game details, Settings, and Downloads screens in French and English.
- Steam and Epic installation discovery across connected drives, with manual rescans.
- Add individual Windows games through a native `.exe` picker, correct the suggested title, and refresh metadata.
- Available Steam game details, artwork, and trailers; optional personal SteamGridDB API key.
- Playtime tracking for games launched through Nexus.
- “Minimal · tactile” interface sounds and a skippable onboarding sequence.

## Downloads

- **Nexus-Launcher-Setup-1.0.0-x64.exe** — Windows installer.
- **Nexus-Launcher-Portable-1.0.0-x64.exe** — portable edition.

Both builds target Windows x64 and are unsigned. Playtime from sessions before using Nexus is not imported. Removing a library entry never removes the game files.
